# 🤖 Sistema Inteligente de Preselección y Evaluación de Candidatos

Sistema de **preselección de hojas de vida basado en Inteligencia Artificial y automatización**, diseñado para apoyar los procesos de selección de personal mediante el análisis de candidatos y la evaluación de perfiles según criterios definidos por el área de Recursos Humanos.

El sistema busca reducir el tiempo dedicado a la revisión manual de hojas de vida y proporcionar una **preselección estructurada y objetiva** de los candidatos que mejor se ajustan a los requisitos establecidos para una vacante.

---

## 🎯 Objetivo

Automatizar parte del proceso inicial de selección de personal mediante un sistema capaz de:

- Analizar hojas de vida de candidatos.
- Identificar información relevante de los perfiles.
- Comparar los perfiles con los criterios definidos para una vacante.
- Evaluar el nivel de correspondencia entre candidato y puesto.
- Generar una preselección de candidatos.
- Facilitar la toma de decisiones por parte del área de Recursos Humanos.

## 🧠 Inteligencia Artificial

La Inteligencia Artificial se utiliza para apoyar el análisis de la información contenida en las hojas de vida y evaluar la correspondencia entre las características del candidato y los requisitos definidos para la vacante.

Los criterios de evaluación pueden incluir aspectos como:

- Experiencia laboral.
- Formación académica.
- Habilidades técnicas.
- Conocimientos requeridos.
- Experiencia relacionada con el cargo.
- Otros criterios establecidos por Recursos Humanos.

> **Importante:** el sistema está diseñado como una herramienta de apoyo para la preselección y no como un reemplazo de la decisión final del equipo de Recursos Humanos.

---

## 🔄 Automatización

La automatización permite conectar las diferentes etapas del proceso y reducir tareas repetitivas relacionadas con la recepción, análisis y clasificación inicial de candidatos.

Esto permite que el equipo de Recursos Humanos pueda dedicar más tiempo a las etapas que requieren evaluación humana y toma de decisiones.

## 📌 Caso de uso

Una empresa publica una vacante con determinados requisitos.

El sistema recibe las hojas de vida de los candidatos y analiza la información relevante de cada perfil. Posteriormente, compara dicha información con los criterios definidos por Recursos Humanos y genera una preselección de los candidatos que presentan mayor correspondencia con el perfil buscado.

De esta manera, el equipo de selección recibe una primera clasificación que puede utilizar como apoyo para continuar con el proceso de contratación.
